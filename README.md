# apt repository for Tabula

[Tabula](https://github.com/bhumit070/tableplus_rs) is a database client for
PostgreSQL, MySQL, SQLite, Redis and MongoDB. This repository is served by
GitHub Pages as a signed apt repository for Debian and Ubuntu (x86_64).

```sh
curl -fsSL https://bhumit070.github.io/tabula-apt/tabula.gpg \
  | sudo tee /usr/share/keyrings/tabula.gpg >/dev/null
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/tabula.gpg] https://bhumit070.github.io/tabula-apt stable main" \
  | sudo tee /etc/apt/sources.list.d/tabula.list
sudo apt update && sudo apt install tabula
```

`sudo apt upgrade` picks up new releases. Signing key fingerprint:
`283C 8944 4C8D ECC2 F353 0F02 8898 FBC0 F87C 21BA`.

Everything here is generated by the release workflow in
[bhumit070/tableplus_rs](https://github.com/bhumit070/tableplus_rs)
(`packaging/apt/update-repo.sh`) and force-pushed as a single commit, so
don't commit here by hand.
